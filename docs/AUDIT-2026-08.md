## 2. What the science & market say (Aug 2026)

- **Demand for small-model local coding is real and documented**: r/LocalLLaMA threads on 8GB VRAM coding setups; #1 failure cause is Ollama's default 2–4k context truncation; tool-calling stalls with weak models; CPU offload unusable (1–2 tok/s).
- **Small models can't agentic-code alone** — that's your thesis validated: Aider edit leaderboard qwen2.5-coder 32b=72.9%, 14b=61.7%, 7b=51.9%; SWE-bench Verified Qwen2.5-Coder-32B ≈9% vs frontier 75–96%; BFCL shows 1B–9B handle simple tool calls but fail multi-step **unless the harness compensates** (robust parsing, retries, constrained decoding).
- **Incumbents are huge but generic**: Aider/OpenHands/Goose all support Ollama/llama.cpp, yet none is *tuned* for sub-10B reliability on consumer GPUs. The wedge is harness-level compensation for model weakness, not another provider wrapper.

**Steal-list (source → pattern → target):**
1. Aider `whole` edit format → don't ask small models for diffs; request full file, apply externally (51% vs ~11% on diff formats).
2. Aider/OpenHands context auto-bump → force `num_ctx` 32k+ at startup instead of Ollama defaults.
3. Goose native-vs-emulated tool calling + parser retries → 25%→90% tool-call success without fine-tuning.
4. Per-task model routing by VRAM tier (7B fast edits ↔ 35B-A3B MoE reasoning).
5. Constrained decoding (GBNF/xgrammar) + quant-aware defaults (Q4 safe for Qwen3, collapses Llama −23pts) — you already proved +38pp with grammar_lazy.

## 3. Overlap with Apohara (the strategic finding)

Your own repo plan already called for vendoring `apohara-agentguard` v0.2.0 (~50 LOC adapter estimate). Today's `guard.rs` (1.5k LOC regex) closes classic bypasses (`sh -c`, `awk system`, eval) but is strictly weaker than agentguard's bounded gate + Landlock/seccomp sandbox, and sandbox.rs is stubs. Meanwhile:

| Apohara satellite | Role in Kitty Code |
|---|---|
| **agentguard** | replace/augment guard.rs + make sandbox.rs real (vendored crate or subprocess hook) |
| **codesearch** | MCP server for repo search inside Kitty sessions |
| **compliance** | map Kitty agent actions → OWASP ASI evidence when running unattended |
| **sealchain** | sign benchmark artifacts & releases (Harbor results become verifiable receipts) |
| **argus** | review PRs written by Kitty before humans see them |

This reframes the ecosystem: Kitty Code becomes the **agent surface** the satellites protect and serve — a stronger funnel than any standalone product story.

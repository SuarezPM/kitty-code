**Learned**:
- `SandboxConfig::default()` usa `current_dir()` con fallback `PathBuf::from(".")` -> no unwrap, workspace auto. Alternativa `SandboxConfig::new(current_dir)` requiere manejo IO; default es suficiente per spec `(o con workspace current_dir)`.

- `cargo test -- sandbox guard` syntax es `cargo test -- -- sandbox guard` (tras `--`), no directo. `bash_timeout_secs` profile (30 tiny /60 medium /120 large) sigue vigente; sandbox `cpu_timeout_secs` 30 es independiente (env hint), no reemplaza tokio timeout.
- Clippy limpio sin warnings; `tools.rs` 1031 LOC supera ideal 250 pero era 966 ya — split futuro `tools/bash.rs` candidato, no bloquea W1.
- Evaluar `check_path` para writes: spec dice "Asegurar check_path para comandos que escriben? Por ahora solo apply env hints." → no se añade check_path en Bash (Bash no conoce paths), queda para Write/Edit en task 6/7.
